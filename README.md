# ModHub

ModHub 是 Degrees of Lewdity（DoL）的模组管理套件，基于 ModLoader 2.x 与 TweeReplacer，提供游戏内管理、市场安装、时间点还原和问题排查，沿用 DoL 原生暗黑风格并适配触屏。

[下载安装](https://github.com/JohnLiao501/ModHub/releases) · [更新日志](CHANGELOG.md) · [在线模组目录](https://dol.alseece.top/modhub/)

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 模组管理 | 单个或批量导入，启用、禁用、删除，拖拽排序与依赖排序。 |
| 模组市场 | 搜索社区模组与美化，选择版本、语言和包型，检查前置与版本要求，批量安装及更新。 |
| 时间点还原 | 保存模组包与管理配置，预览变更并恢复，加载异常时提供救援入口。 |
| 美化管理 | 调整已加载图包的启禁及覆盖顺序，保存后刷新支持的画布。 |
| 模组说明 | 阅读包内 ReadMe；缺少本地说明时尝试在线获取并缓存。 |
| 加载日志 | 筛选日志、查看错误与关联模组，导出诊断长图。 |
| 帮助中心 | 本地排查、配置修复、自填 API 的 AI 辅助分析，以及经双方确认的远程协助。 |
| 兼容性检查 | 核对配置、聚合补丁共同目标与相关日志，在原页查看依据和未覆盖范围。 |
| 言灵 | 查阅和复制社区配方、使用条件与步骤，复制时不执行正文。 |

管理操作期间，加载圆环显示在操作按钮内，状态说明保留文字。启禁和排序会先显示待保存结果；配置保存及还原点整理完成后才能继续修改或重新载入。取消操作前备份时撤销预览，保存失败时按重新读取的实际配置显示。

管理页先显示已读取的模组列表，包体资料和配置核对完成后再开放操作。折叠的美化与核心模组列表在展开时生成；日志内容未变时复用分析结果，帮助首页共用一次日志读取与分析，减少切换页面时的重复工作。

## 安装与入门

1. 准备带有 ModLoader 2.x 的 DoL 游戏，并安装满足要求的 TweeReplacer。
2. 从 [GitHub Releases](https://github.com/JohnLiao501/ModHub/releases) 的 Assets 下载 **`ModHub-v<版本号>.zip`** 正式附件。
3. 在游戏原生模组管理器，或已有 ModHub 的【导入模组】中选择该 ZIP，确认启用。
4. 保存游戏进度后重新载入，通过游戏顶栏或侧栏的【ModHub】进入。

**请勿将 GitHub 自动生成的 `Source code (zip)` 当作模组包导入。** 正式包的 ZIP 根目录直接包含 `boot.json`；重命名源码包不能改变其目录结构。

当前界面适配基线为 DoL 0.5.12.13 / ModLoader 2.101.1。其他游戏版本及第三方模组组合仍需分别核对；ModHub 的前置要求见 [boot.json](src/boot.json)。

## 常用操作

### 管理与导入

在【模组管理】导入 `.zip`、`.modpack` 或 `.modpack.crypt`，支持混合批量选择。ModPack 依赖加载器原生解析能力；需要密码的包目前没有密码输入入口。

拖动手柄可调整加载顺序，也可使用依赖排序。单个导入有 ReadMe 时打开说明；批量导入保留管理页并汇总结果。启禁、安装和顺序变更通常需要重新载入，**重载前请先保存游戏进度**。

顶部常驻【导入模组】和【重新载入游戏】；点击【更多工具】打开单列浮出菜单，可使用智能排序、刷新列表、兼容性检查和时间点还原。点击工具右侧的固定按钮，可将常用工具放到【更多工具】左边，再次点击可取消，选择保存在当前浏览器。菜单支持方向键选择、Escape 关闭和点击外部关闭；窄屏操作栏可横向滚动，按钮文字保持单行。

滚动列表时，配置状态和核心操作栏保持吸顶，进入多选后批量操作栏也保持可见；排序说明与安全模式随页面滚动，桌面与窄屏均保留更多的模组阅读空间。

### 市场安装与更新

1. 在【模组市场】搜索或筛选，名称支持中文、拼音全拼和首字母。
2. 有多个语言、分支或包型时，先切换卡片选项，再选择安装或更改版本。
3. 在同一窗口选择版本、附加资源与前置，查看安装详情，点击【下载并安装】后自动检查并安装。
4. 完成后可选择【稍后重载】，继续留在市场安装其他模组。

已安装附加项更新时默认勾选并保留启禁状态；未安装项默认不选。本次手动取消的选择会继续保留。已登记的互斥分支在切换前说明停用与启用安排，保留旧包和存档；语言包按各自规则确认共存。

切换语言、发行分支或安装版本时，仅更新当前卡片，不再显示额外的加载图标和提示行；读取在线版本期间可继续切换。普通浏览保持卡片位置，刷新或调整筛选时重新排序；状态筛选仍会及时移除不符合条件的卡片。

下载和等待确认状态使用统一圆环，只有实际下载时显示百分比。批量操作栏集中列出各模组的进度、检查和安装结果，可展开查看需要处理的前置模组；无需操作的已就绪前置不再列出。展开或收起的选择在进度刷新后保持。默认选择 GH-Proxy 镜像，也可手动选择线路；失败时按线路顺序尝试其他镜像，再尝试自建反代及其 Worker 原域备用入口。附加资源单独下载与核验，不沿用主包临时回退的线路。

下载后仅新增安装内容、启停范围变化或明确不适配、降级、缺失前置时再次集中确认；新增第三方前置先取得下载确认。可能共享补丁目标、适配尚未注明和检查未覆盖的内容保留在可展开的检查结果中，不单独打断安装。包体身份、完整性和写入前状态核验继续执行。

下载线路依次提供 GH-Proxy、LLKK、FastGit、DDLC、Boki 五个镜像站，自建反代位于倒数第二项，GitHub 浏览器手动下载位于最后一项。第三方线路可能受限额、访问策略及网络环境影响，失败时会自动尝试其他候选，完整性检查不会跳过。

已上架的社区模组与 Wiki 模组共用下载安装和历史版本回退流程，不在安装前单独请求社区审核接口；包体身份、摘要、依赖和已知下架状态按同一规则处理。

市场各处总数统一按上架产品统计，同一产品的语言或发行选项合并计数；搜索和筛选会单独显示当前结果数。已确认失效的条目不再上架，临时网络失败不作为下架依据。

打开市场时先显示已有内存目录或最近成功的缓存，目录请求与本地模组检查并行执行；缓存预览期间暂停安装，待本轮核对完成后恢复。主索引响应较慢时启动备用入口，采用先返回的有效索引；卡片筛选、统计与更新检查复用本轮匹配结果，减少重复扫描。

每次游戏启动完成后，ModHub 会利用空闲时间静默检查一次已安装模组的更新，并在侧栏入口显示数量，无需先打开面板。后台检查最多同时执行两项，页面隐藏或正在导入、安装、还原时暂缓；打开面板共用检查请求与结果，需要重新核对时可点击【刷新】。

市场顶部依次显示板块、安装状态、搜索与筛选。点击【全部】【已装】【可更新】【可安装】【已忽略】即可切换状态，其中全部、已装和可更新显示对应数量；状态切换保留当前分类、搜索和排序。【可安装】包含尚未安装和可更新的模组；需要清除全部条件时使用【返回全部模组】。搜索框右侧提供刷新图标；【更多】与【多选安装】并排，投稿、下载线路和资料来源位于【更多】中。点击社区入口右侧的图钉，可将按钮固定到操作栏，再次点击可取消，选择保存在当前浏览器；窄屏固定按钮自动换行。【多选安装】进入多选后显示完整操作和吸顶进度栏。

可读取的市场目录中，简介明确说明且名称能唯一对应技术身份的框架前置，会与目录及安装包声明一起检查，例如“依赖某框架”或“通过某框架制作”。条件、可选、否定、历史移除或仅兼容的说明不自动作为必需前置；没有声明版本要求时不额外增加版本限制。

【多选安装】用于选择多个模组，【一键全部更新】先进入选版汇总，可调整或跳过项目。多选以卡片当前显示的语言、分支或安装版本为准，已安装的选项不显示勾选；切换选项会清除该卡片原有勾选。卡片已显示的有效选项直接用于安装，无需重复选择；全部更新沿用实际已安装的选项。

多选期间暂停卡片内的单项安装，退出后恢复，并清空本轮选择和结果列表。开始批量安装后先打开选版窗口，显示本地核对与版本读取状态，等待期间可取消。批量进度只统计本次选择的模组，需要处理的前置在详情中列出；上次结果可逐条删除或全部清除。安装按依赖关系逐项执行，停止或失败不会撤销此前成功的项目。

批量安装和全部更新按依赖分组处理，最多同时下载两个已确认的安装包，依赖核验和安装仍按顺序进行，独立模组无需等待整批包体。下载与准备缓存共用 256 MB 上限，大小未知或剩余空间不足时顺序下载。共享需要变更的前置时集中核验；包体发现额外依赖或跨组覆盖时，先合并剩余目标重新检查，并复用已下载包体。每组完成后释放准备缓存，后续组不能替换或停用已完成项目使用的模组；停止后不再开始新的下载，已在途的下载结束后清理，整批共用一个还原上下文，结束后统一提示重新载入。市场多选和安装期间批量操作栏保持吸顶，可随时查看进度或停止后续处理。

推荐版本依据作者说明、安装包名称及已登记的版本信息。支持的游戏版本尚未注明时，会在选版页面提示；仅提供外部来源的条目须按原帖下载。

### 美化、说明与日志

已加载图包的启禁和覆盖顺序保存后，可即时刷新支持的图像缓存与画布；新增图包仍需重载。普通美化文件应按对应框架说明安装。

在【模组说明】查看作者 ReadMe；遇到异常时先查看【加载日志】，保留错误原文和触发步骤，再进入【帮助中心】排查。

本地 ReadMe 有内容时直接显示，不等待市场联网。缺少本地说明时仍尝试市场资料与作者仓库，线上读取失败时保留模组自身信息和具体状态。

### 兼容性检查

在【模组管理】打开【更多工具】，点击【兼容性检查】。首屏只显示一句具体提醒，展开后查看缺少前置、版本要求、加载顺序或可能冲突的原因；详细声明和日志继续按需展开。【求助报告】中可预览并复制完整依据。检查在本地读取声明，不修改启禁配置，不调用 AI 或上传包体。

枫叶框架已兼容简易框架，安装和启用时不再仅因两者同时存在提示冲突。实际前置、版本和包体校验仍按各自声明执行。

支持 TweeReplacer 内联和外置 JSON5 参数、原生 `replacePatchList` 及 `ReplacePatcherAddon` 的 JS/CSS/Passage 目标。相同目标不等于必然冲突，普通同名 JS/CSS 也不直接作为冲突依据。动态脚本、未知插件、无法读取或超出限额的资源会说明未覆盖原因。

插件的 `addonPlugin.modVersion` 与提供者安装包版本不是可直接替代的同一项资料。加载器没有提供标准插件接口版本时，该要求标注为尚未核对；正式前置的 `dependenceInfo` 版本要求仍按实际提供者校验。

安装预览将“请注意”提醒置于顶部并标红，展开可查看具体原因；随后列出将安装或启用的模组，名称以金色标题和包体图标突出显示，已满足的前置显示为“前置模组已就绪”。选版页面统一使用“安装版本”；相同原因合并提示，涉及模组集中列出，各自版本和独特要求保留在详情中。文件名、前置版本和加载器要求收在详情中；同类兼容性问题合并展示，具体目标和原始依据仍可逐项查看，安装前日志不作为安装后异常结论。市场下载并验证后，按实际主包、前置和附加包检查安装内容，新增发现纳入既有安装计划核对；原有身份、摘要和依赖校验继续生效，确认期间配置或包体变化会要求重新检查。

## 时间点还原

在【模组管理】展开【更多工具】并打开【时间点还原】，选择时间点，查看受影响的模组并确认还原。恢复前会保存当前状态，核验完成后重新加载。

读取还原点、扫描变更和执行还原时显示加载状态。扫描详情页底部仅保留【返回】，返回后保留所选还原点。

- 覆盖旁加载模组包、启禁状态、加载顺序及美化管理配置。
- **不恢复游戏存档、游戏 HTML 或内嵌模组**，也不能补回建点时已经缺失的包体。
- 自动建点默认开启，普通历史默认保留 20 点；受保护点额外保留。手动保护须自行解除，系统保护会显示原因及解除条件。
- 还原记录保存在当前加载器的本地存储中；请另行备份重要游戏存档，清除浏览器数据可能丢失本地记录。

加载异常或停滞时，可使用加载页出现的恢复入口。ModHub 尚未运行、已被禁用或卸载，以及页面完全冻结时，模组内救援可能不可用。保护性修改与还原需要浏览器支持 Web Locks，并避免多个游戏窗口同时修改。

## 帮助中心与隐私

可先展开常见问题执行本地检查。配置修复会预览将启用的已安装前置或将保存的顺序；保存成功后仍需重载并复现原问题验证效果。

**AI 协助**需自行填写支持浏览器跨域访问的 Chat Completions 兼容服务、模型和密钥。预览分析材料并确认发送后，才向所选服务提交问题、日志和相关声明源码；自动补充限于已确认范围。AI 不读取游戏存档，生成的修改须另行预览确认，应用前建立还原点。建议可能出错，后续更新或重新导入原包会覆盖修改。

密钥默认仅保留在本次页面内存，勾选【记住我】后存于当前浏览器。服务可能收费，日志脱敏也无法识别所有私人信息，请在发送前核对材料与服务方的数据政策；同一游戏环境中的其他模组可能读取内存或已保存的密钥。

**远程协助**由协助者生成一次性协助码，玩家输入并确认连接；双方在 ModHub 内聊天并逐项预览、确认资料分享或修改。连接本身不自动分享诊断和源码，后台收信不执行操作，也不提供屏幕共享或整机控制。

远程 JS 指令具有游戏页面权限，运行前强制建立受保护时间点并备份原生游戏存档；备份不能撤销网络请求或其他脚本副作用。协助者填写的名称不能证明身份，请确认协助码来源。详细范围见 [远程协助协议](docs/modhub-remote-assistance-protocol.md)。

## 常见问题

- **导入提示 `boot.json` 无效**：确认下载的是 Releases 中的正式附件，且 ZIP 根目录含有 `boot.json`。
- **原版图片、天气或天空效果报错**：分离图片的游戏需要另装对应版本的 `GameOriginalImagePack`。请从[游戏发行版](https://github.com/Eltirosto/Degrees-of-Lewdity-Chinese-Localization/releases)获取；ModHub 和可选美化不能替代原版图片包。
- **市场读取失败或资料较旧**：先点击【刷新】。断网或来源故障时可能显示最近成功的缓存，安装与版本查询仍受来源可用性影响。
- **AI 连接失败**：核对地址、模型、密钥及浏览器跨域支持；本地 HTML 的来源通常为 `Origin: null`，客户端不能替服务端补齐跨域响应头。

## 社区收录与反馈

在市场【更多】中使用【申请上架 / 推荐模组】提交自己或其他作者的作品，也可申请资料纠错、下架或投稿言灵。提供作者原始来源和必要说明，人工审核后才进入公开目录；收录不保证第三方代码安全或适配所有组合。

通过【我的投稿】查询进度或补充材料，并妥善保存查询凭证。新申请需要联网和验证码验证，无需 GitHub 账号。市场与[在线目录](https://dol.alseece.top/modhub/)共用资料来源。

## 开发与文档

运行源码位于 `src/`，版本以 `src/boot.json` 为准；更新记录统一放在 [CHANGELOG.md](CHANGELOG.md)，开发与发布要求见 [AGENTS.md](AGENTS.md)。

根目录 `tests/` 仅在本地保留，由 `.gitignore` 排除。首次克隆后如需回归，可从 v1.6.0 历史提交恢复到工作区：

```powershell
git restore --source=f6b9b1b --worktree -- tests/
```

此命令不重新跟踪测试；恢复的用例仍须按当前源码维护，修改后另行备份。缺少用例时不能据此声称回归通过。

- 核心回归：`node src/test-smart-sort.js`
- 身份与提取器：`node test-dol-mod-extractor.js`
- 打包策略：`python tests/test_pack.py`
- 本地打包：`python pack.py`
