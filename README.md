# ModHub

ModHub 是 Degrees of Lewdity（DoL）的模组管理套件，基于 ModLoader 2.x 与 TweeReplacer，提供游戏内管理、市场安装、时间点还原和问题排查，沿用 DoL 原生暗黑风格并适配触屏。

[下载安装](https://github.com/JohnLiao501/ModHub/releases) · [更新日志](CHANGELOG.md) · [在线模组目录](https://dol.alseece.top/modhub/)

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 模组管理 | 单个或批量导入，启用、禁用、删除，拖拽排序与依赖排序。 |
| 模组市场 | 搜索社区模组与美化，选择版本、语言和包型，检查前置与版本要求，批量安装及更新。 |
| 时间点还原 | 保存模组包与管理配置，预览变更并恢复，加载异常时提供救援入口。 |
| 美化管理 | 调整已加载图包的启禁及覆盖顺序，保存后刷新支持的画布。 |
| 模组说明 | 阅读包内 ReadMe；缺少本地说明时尝试在线获取并缓存。 |
| 加载日志 | 筛选日志、查看错误与关联模组，导出诊断长图。 |
| 帮助中心 | 本地排查、配置修复、自填 API 的 AI 辅助分析，以及经双方确认的远程协助。 |
| 兼容性检查 | 核对配置、聚合补丁共同目标与相关日志，在原页查看依据和未覆盖范围。 |
| 言灵 | 查阅和复制社区配方、使用条件与步骤，复制时不执行正文。 |
| 界面与内容语言 | 简体中文、繁體中文、English 即时切换；市场统一展示中文目录，保留产品的安装包语言选项。 |

管理操作期间，加载圆环显示在操作按钮内，状态说明保留文字。启禁和排序会先显示待保存结果；配置保存及还原点整理完成后才能继续修改或重新载入。取消操作前备份时撤销预览，保存失败时按重新读取的实际配置显示。

管理页先显示已读取的模组列表，包体资料和配置核对完成后再开放操作。折叠的美化与核心模组列表在展开时生成；日志内容未变时复用分析结果，帮助首页共用一次日志读取与分析，减少切换页面时的重复工作。

## 安装与入门

1. 准备带有 ModLoader 2.x 的 DoL 游戏，并安装满足要求的 TweeReplacer。
2. 从 [GitHub Releases](https://github.com/JohnLiao501/ModHub/releases) 的 Assets 下载 **`ModHub-v<版本号>.zip`** 正式附件。
3. 在游戏原生模组管理器，或已有 ModHub 的【导入模组】中选择该 ZIP，确认启用。
4. 保存游戏进度后重新载入，通过游戏顶栏或侧栏的【ModHub】进入。

**请勿将 GitHub 自动生成的 `Source code (zip)` 当作模组包导入。** 正式包的 ZIP 根目录直接包含 `boot.json`；重命名源码包不能改变其目录结构。

当前界面适配基线为 DoL 0.5.12.13 / ModLoader 2.101.1。其他游戏版本及第三方模组组合仍需分别核对；ModHub 的前置要求见 [boot.json](src/boot.json)。

DoLP 会分别识别 DoL 基线、DoLP 分支及其自身版本；普通 DoL 版本范围不能证明 DoLP 适配，未核验分支的包保留手动选择与安装确认。已用官方 DoLP v0.778（DoL 0.5.12.11）和隔离注入的 ModLoader 2.101.1、TweeReplacer 1.7.0 验证入口及真实模组还原；官方 DoLP 原生包不含这些加载器组件。验证组合与边界见 [DoLP 兼容性核验](docs/modhub-dolp-compatibility.md)。

官方原生 DoLP 的网络策略会阻止外部市场连接。按当前维护决定，不放宽该策略，停止 DoLP 在线市场适配；已完成的版本识别、本地管理和还原验证保留。

## 常用操作

### 界面语言与市场目录

模组管理页设置行以小按钮显示当前界面语言，展开后直接点选简体中文、繁體中文或 English，无需再打开下拉框。时间点还原与加载页救援面板跟随同一界面语言，标题栏不再放置语言选择器。首次按浏览器语言选择，无匹配时使用英语；手动选择保存在当前浏览器。三语字典随安装包提供，无需在线翻译。切换语言保留输入、连接和界面状态；正在安装、还原或执行 AI、远程操作时，请完成或取消操作后再切换。

市场统一展示中文目录（含简体与繁体），不再提供目录语言筛选；旧语言偏好不再影响展示，切换界面语言也不会切换目录。同一产品保留已登记的全部安装包语言选项。目录资料来源包括中文 Wiki、作者 GitHub 发布、[Discord 社区](https://discord.com/channels/1103864219620884560/1197809298902896731)及百度贴吧，请通过各条目的来源链接核对作者说明。

卡片名称、简介、分类和标签跟随界面语言显示；优先使用作者多语字段，其次使用随包维护的译文，可展开【查看原文】。源文更新或暂缺译文时保留原文并提示，不把旧译文套用到新简介；搜索同时支持原文与当前译文。作者署名、技术名称、版本号、帖子正文、ReadMe、原始日志、用户输入和 AI 回复保留原文。界面语言偏好不随时间点还原回滚。仍受支持的已安装模组可继续更新、检查依赖和补全说明；有更新未包含在中文目录内时，【查看更新】会定位管理页的更新条目。

1.8.0 新增的 Discord 英文目录批次已撤回，并停止市场支持，包含同批后来补充 GitHub 来源的项目。1.8.1 同时阻止旧缓存、Wiki 回退和旧安装计划重新开放此批次；玩家已安装的包保留，由模组管理自行处理。原中文目录仅补充 Discord 来源的项目按原范围保留。历史[收录草稿](docs/modhub-english-catalog-draft.json)仅作为调查记录，不代表当前支持或作者授权；新的收录与下载资格须分别核实作者许可。1.9.0 与 GitGud 接入已取消。

尚未登记发布状态时，统一索引可依据当前产品正式附件及 GitHub 的草稿、预发布标志补齐状态，明确登记的作者状态优先。卡片不显示“发布状态未确认”徽标，仍保留制作中和预发布提示；隐藏徽标不将未知状态改为已发布。派生证据绑定具体来源、发布页、身份及安装范围；换源或移除社区资料后不沿用旧状态，也不因此开放安装资格。

市场资料来自中文 Wiki、作者 GitHub 发布、Discord 社区及百度贴吧，卡片保留各自来源链接与获取说明。GitHub 链接仅证明资料来源；只有已核验的安装包开放一键安装。已确认作者 Release、但包体或升级关系仍待核验的项目提供 GitHub 手动获取入口，并说明限制。

- “小小PC修复增强”作为“小小PC”的独立衍生条目保留；对 Wiki 误指向服装图标工具的仓库链接作已核实的来源修正，避免同源合并隐藏该项目，不因此开放安装资格。
- “可追溯性-模组来源显示”的主标题与副标题分段时，按已核实的作者完整名称和仓库恢复显示；其他确有多项目歧义的行继续保留核对要求。

卡片语言徽标仅保留有明确依据的【繁体中文】，不再显示简体中文、英语、英文来源或语言未标注徽标。隐藏徽标不改写包语言资料、制作状态或安装资格，语言版本切换器及安装选项继续保留。资料随包提供，旧索引和缓存也可使用；具体依据见 [模组语言核验记录](docs/market-package-language-evidence.json)。

多语言及多版本分组卡片按当前选中版本显示分类与功能标签；例如智能手机原版显示玩法与内容、社交、剧情及 NPC，切换 Omega 后显示其自身的外观与资源、服装标签。

ModHub 自身不显示语言徽标，美化修正不显示“翻译”功能标签；这些显示调整不改写对应的语言证据及目录原始标签。

已确认主要用途为图像、头像或服装美化的资源条目可隐藏卡片语言徽标，RAY 额外服装继续保留已核验的下载入口。隐藏徽标不改写包内文本及语言资料；独立语言版本的切换器和安装选项继续保留。

AU 的染发优化、面部扩展及 RAY 额外服装折入对应主模组的【选择附加内容】，在选版窗口中使用与枯木音频扩展相同的可选复选框，不再单独占用市场卡片。未安装的附加默认不选，已安装项可继续检查更新；各附加保留独立版本、来源、安装身份及前置检查，不能因同仓库而合并包体或停用另一项。RAY 主包及尚未核验自动安装身份的附加仍按作者说明手动获取，不因整合附加而开放一键安装。主条目不可浏览时保留附加的独立入口；必要框架前置及 Omega 等发行分支不作为可选附加。

搜索框有输入时，右侧显示清空按钮。点击后立即清除当前板块的搜索文字并返回输入框，保留分类、状态及另一板块的搜索。

### 管理与导入

在【模组管理】导入 `.zip`、`.modpack` 或 `.modpack.crypt`，支持混合批量选择。ModPack 依赖加载器原生解析能力；需要密码的包目前没有密码输入入口。

拖动手柄可调整加载顺序，也可使用依赖排序。单个导入有 ReadMe 时打开说明；批量导入保留管理页并汇总结果。启禁、安装和顺序变更通常需要重新载入，**重载前请先保存游戏进度**。

顶部常驻【导入模组】【重新载入游戏】和【智能排序】，统一采用主要操作按钮。右侧刷新图标直接重新读取列表，位于【更多工具】左边；菜单保留兼容性检查和时间点还原。点击工具右侧的固定按钮，可将常用工具放到操作栏，再次点击可取消，选择保存在当前浏览器。旧刷新固定记录不会重复生成入口。菜单支持方向键选择、Escape 关闭和点击外部关闭；窄屏按钮自然换行。

滚动列表时，配置状态和核心操作栏保持吸顶，进入多选后批量操作栏也保持可见；排序说明与安全模式随页面滚动，桌面与窄屏均保留更多的模组阅读空间。

### 市场安装与更新

1. 在【模组市场】搜索或筛选，名称支持中文、拼音全拼和首字母。
2. 有多个语言、分支或包型时，先切换卡片选项，再选择安装或更改版本。
3. 在同一窗口选择版本、附加资源与前置，查看安装详情，点击【下载并安装】后自动检查并安装。
4. 完成后可选择【稍后重载】，继续留在市场安装其他模组。

已安装附加项更新时默认勾选并保留启禁状态；未安装项默认不选。本次手动取消的选择会继续保留。已登记的互斥分支在切换前说明停用与启用安排，保留旧包和存档；语言包按各自规则确认共存。

切换语言、发行分支或安装版本时，仅更新当前卡片，不再显示额外的加载图标和提示行；读取在线版本期间可继续切换。普通浏览保持卡片位置，刷新或调整筛选时重新排序；状态筛选仍会及时移除不符合条件的卡片。

【下载任务】入口以金色处理状态、绿色完成标记、红色未完成提示区分结果；取消、跳过或仍有未结束记录时显示中性状态。仅下载达到 100% 不代表安装完成，仍须等待安装结果。入口保留任务数量，具体原因可展开查看。

下载和等待确认状态使用统一圆环，只有实际下载时显示百分比。操作栏的【下载任务】显示进行中任务和结果数量，展开浮动面板查看进度、前置与安装结果；取消后的记录继续保留，不再撑开市场筛选区。收起、点击面板外部或按 Escape 只隐藏面板，停止后续与清理记录仍独立操作；展开状态和滚动位置在进度刷新后保持。下载方式采用简短名称，下方说明自动备用与手动导入步骤；已有选择及下载顺序保持。尚未手动设置线路时，英文界面默认 GitHub 直连优先，中文界面默认 GH-Proxy 镜像；已有线路选择优先，切换界面语言不会覆盖。每个附件自动最多尝试三个不同线路，不重复尝试同一线路；仍可手动更换下载线路。没有可信摘要时仅使用作者 GitHub Release 原站与受控下载接口，不能用本地缓存自行计算的摘要替代作者发布认证。带可信摘要时才允许自动使用第三方镜像，下载后仍须核对摘要、包内身份及安装要求。服务端明确撤回下载授权或无法核验当前目录时停止自动安装。附加资源分别下载与核验。

下载后仅新增安装内容、启停范围变化或明确不适配、降级、缺失前置时再次集中确认；新增第三方前置先取得下载确认。可能共享补丁目标、适配尚未注明和检查未覆盖的内容保留在可展开的检查结果中，不单独打断安装。包体身份、完整性和写入前状态核验继续执行。

下载线路提供 GH-Proxy、LLKK、FastGit、DDLC、Boki 五个镜像站、自建反代和 GitHub 直连优先。GitHub 附件可能受浏览器跨域规则限制，直连优先仍保留自动回退；临时回退不改写用户保存的线路。GitHub 浏览器手动下载单独保留，不计为自动安装成功。第三方线路可能受限额、访问策略及网络环境影响，完整性检查不会跳过。

已上架的社区模组与 Wiki 模组共用下载安装和历史版本回退流程，不在安装前单独请求社区审核接口；包体身份、摘要、依赖和已知下架状态按同一规则处理。

市场各处总数统一按上架产品统计，同一产品的语言或发行选项合并计数；搜索和筛选会单独显示当前结果数。已确认失效的条目不再上架，临时网络失败不作为下架依据。

打开市场时先显示已有内存目录或最近成功的缓存，目录请求与本地模组检查并行执行；缓存预览期间暂停安装，待本轮核对完成后恢复。主索引响应较慢时启动备用入口，采用先返回的有效索引；卡片筛选、统计与更新检查复用本轮匹配结果，减少重复扫描。

每次游戏启动完成后，ModHub 会利用空闲时间静默检查一次已安装模组的更新，并在侧栏入口显示数量，无需先打开面板。后台检查最多同时执行两项，页面隐藏或正在导入、安装、还原时暂缓；打开面板共用检查请求与结果，需要重新核对时可点击【刷新】。

正式发布条目不显示重复状态徽标，制作中、预发布和未核实状态仍提示；英文发布日期标为 Released。多版本切换器、包型选项与安装确认共用显示译文，保留原始包体标识。市场顶部依次显示板块、安装状态、搜索与筛选。点击【全部】【已装】【可更新】【可安装】【已忽略】即可切换状态，其中全部、已装和可更新显示对应数量；状态切换保留当前分类、搜索和排序。【可安装】包含尚未安装和可更新的模组；需要清除全部条件时使用【返回全部模组】。搜索框右侧提供刷新图标；【更多】与【多选安装】并排，投稿、下载线路和资料来源位于【更多】中。尚未保存布局时，【申请上架 / 推荐模组】默认固定在操作栏；点击社区入口右侧的图钉可固定或取消按钮，选择保存在当前浏览器，主动取消后不会再次默认固定；窄屏固定按钮自动换行。【多选安装】进入多选后显示吸顶操作栏，下载与安装进度通过【下载任务】浮窗查看。

可读取的市场目录中，简介明确说明且名称能唯一对应技术身份的框架前置，会与目录及安装包声明一起检查，例如“依赖某框架”或“通过某框架制作”。条件、可选、否定、历史移除或仅兼容的说明不自动作为必需前置；没有声明版本要求时不额外增加版本限制。

【多选安装】用于选择多个模组，【一键全部更新】先进入选版汇总，可调整或跳过项目。多选以卡片当前显示的语言、分支或安装版本为准，已安装的选项不显示勾选；切换选项会清除该卡片原有勾选。卡片已显示的有效选项直接用于安装，无需重复选择；全部更新沿用实际已安装的选项。

多选期间暂停卡片内的单项安装，退出后恢复，并清空本轮选择和结果列表。开始批量安装后先打开选版窗口，显示本地核对与版本读取状态，等待期间可取消。批量进度只统计本次选择的模组，需要处理的前置在详情中列出；上次结果可逐条删除或全部清除。安装按依赖关系逐项执行，停止或失败不会撤销此前成功的项目。

批量安装和全部更新按依赖分组处理，最多同时下载两个已确认的安装包，依赖核验和安装仍按顺序进行，独立模组无需等待整批包体。下载与准备缓存共用 256 MB 上限，大小未知或剩余空间不足时顺序下载。共享需要变更的前置时集中核验；包体发现额外依赖或跨组覆盖时，先合并剩余目标重新检查，并复用已下载包体。每组完成后释放准备缓存，后续组不能替换或停用已完成项目使用的模组；停止后不再开始新的下载，已在途的下载结束后清理，整批共用一个还原上下文，结束后统一提示重新载入。市场多选操作栏保持吸顶，安装期间可通过【下载任务】浮窗查看进度或停止后续处理。

推荐版本依据作者说明、安装包名称及已登记的版本信息。支持的游戏版本尚未注明时，会在选版页面提示；仅提供外部来源的条目须按原帖下载。

### 美化、说明与日志

已加载图包的启禁和覆盖顺序保存后，可即时刷新支持的图像缓存与画布；新增图包仍需重载。普通美化文件应按对应框架说明安装。

在【模组说明】查看作者 ReadMe；遇到异常时先查看【加载日志】，保留错误原文和触发步骤，再进入【帮助中心】排查。

本地 ReadMe 有内容时直接显示，不等待市场联网。缺少本地说明时仍尝试市场资料与作者仓库，线上读取失败时保留模组自身信息和具体状态。

### 兼容性检查

在【模组管理】打开【更多工具】，点击【兼容性检查】。首屏只显示一句具体提醒，展开后查看缺少前置、版本要求、加载顺序或可能冲突的原因；详细声明和日志继续按需展开。【求助报告】中可预览并复制完整依据。检查在本地读取声明，不修改启禁配置，不调用 AI 或上传包体。

枫叶框架已兼容简易框架，安装和启用时不再仅因两者同时存在提示冲突。实际前置、版本和包体校验仍按各自声明执行。

支持 TweeReplacer 内联和外置 JSON5 参数、原生 `replacePatchList` 及 `ReplacePatcherAddon` 的 JS/CSS/Passage 目标。相同目标不等于必然冲突，普通同名 JS/CSS 也不直接作为冲突依据。动态脚本、未知插件、无法读取或超出限额的资源会说明未覆盖原因。

插件的 `addonPlugin.modVersion` 与提供者安装包版本不是可直接替代的同一项资料。加载器没有提供标准插件接口版本时，该要求标注为尚未核对；正式前置的 `dependenceInfo` 版本要求仍按实际提供者校验。

安装预览将“请注意”提醒置于顶部并标红，展开可查看具体原因；随后列出将安装或启用的模组，名称以金色标题和包体图标突出显示，已满足的前置显示为“前置模组已就绪”。选版页面统一使用“安装版本”；相同原因合并提示，涉及模组集中列出，各自版本和独特要求保留在详情中。文件名、前置版本和加载器要求收在详情中；同类兼容性问题合并展示，具体目标和原始依据仍可逐项查看，安装前日志不作为安装后异常结论。市场下载并验证后，按实际主包、前置和附加包检查安装内容，新增发现纳入既有安装计划核对；原有身份、摘要和依赖校验继续生效，确认期间配置或包体变化会要求重新检查。

## 时间点还原

在【模组管理】展开【更多工具】并打开【时间点还原】，选择时间点，查看受影响的模组并确认还原。恢复前会保存当前状态，核验完成后重新加载。

读取还原点、扫描变更和执行还原时显示加载状态。扫描详情页底部仅保留【返回】，返回后保留所选还原点。

- 覆盖旁加载模组包、启禁状态、加载顺序及美化管理配置。
- **不恢复游戏存档、游戏 HTML 或内嵌模组**，也不能补回建点时已经缺失的包体。
- 自动建点默认开启，普通历史默认保留 20 点；受保护点额外保留。手动保护须自行解除，系统保护会显示原因及解除条件。
- 还原记录保存在当前加载器的本地存储中；请另行备份重要游戏存档，清除浏览器数据可能丢失本地记录。

加载异常或停滞时，可使用加载页出现的恢复入口。ModHub 尚未运行、已被禁用或卸载，以及页面完全冻结时，模组内救援可能不可用。保护性修改与还原需要浏览器支持 Web Locks，并避免多个游戏窗口同时修改。

## 帮助中心与隐私

可先展开常见问题执行本地检查。配置修复会预览将启用的已安装前置或将保存的顺序；保存成功后仍需重载并复现原问题验证效果。

**AI 协助**是可选功能，安装包不包含模型、模型权重或浏览器推理引擎。玩家需自行填写支持浏览器跨域访问的 Chat Completions 兼容服务、模型和密钥；浏览器直接连接该地址，地址可以是云端服务，也可以是玩家自行运行的本机回环服务。ModHub 在本机收集材料、校验回复并应用已确认修改，推理由玩家选择的服务执行。

保存连接设置不会发送请求。【测试连接】发送模型名和简短测试消息；分析前可预览并确认发送问题描述、游戏与加载器版本、模组及启禁列表、错误和警告日志、选中源码与包声明。已确认的补充范围可包括目录、游戏只读段落及前轮诊断；密钥通过 Authorization 请求头发给所选服务。代码未主动收集游戏存档，但日志、描述、源码或手动分享内容仍可能含有私人信息。日志脱敏不能保证清除全部隐私。AI 修改须另行预览确认，应用前建立还原点；建议可能出错，后续更新或重新导入原包会覆盖修改。

密钥默认仅保留在本次页面内存，勾选【记住我】后以明文存于当前浏览器的 localStorage。服务可能收费，日志脱敏也无法识别所有私人信息，请在发送前核对材料与服务方的数据政策；同一游戏环境中的其他模组可能读取内存或已保存的密钥。

**远程协助**的聊天和经玩家确认分享的资料通过服务端 Worker 与 D1 中转保存，不是设备间直连。由协助者生成一次性协助码，玩家输入并确认连接；双方在 ModHub 内聊天并逐项预览、确认资料分享或修改。连接本身不自动分享诊断和源码，后台收信不执行操作，也不提供屏幕共享或整机控制。

远程 JS 指令具有游戏页面权限，运行前强制建立受保护时间点并备份原生游戏存档；备份不能撤销网络请求或其他脚本副作用。协助者填写的名称不能证明身份，请确认协助码来源。第三方模组在加载后同样具有游戏页面权限，来源与摘要校验不能证明其代码无害。详细范围见 [远程协助协议](docs/modhub-remote-assistance-protocol.md)及[安全审查说明](docs/modhub-security-1.8.1.md)。

## 常见问题

- **导入提示 `boot.json` 无效**：确认下载的是 Releases 中的正式附件，且 ZIP 根目录含有 `boot.json`。
- **原版图片、天气或天空效果报错**：分离图片的游戏需要另装对应版本的 `GameOriginalImagePack`。请从[游戏发行版](https://github.com/Eltirosto/Degrees-of-Lewdity-Chinese-Localization/releases)获取；ModHub 和可选美化不能替代原版图片包。
- **市场读取失败或资料较旧**：先点击【刷新】。断网或来源故障时可能显示最近成功的缓存，安装与版本查询仍受来源可用性影响。
- **AI 连接失败**：核对地址、模型、密钥及浏览器跨域支持；本地 HTML 的来源通常为 `Origin: null`，客户端不能替服务端补齐跨域响应头。

## 开发与文档

运行源码位于 `src/`，版本以 `src/boot.json` 为准；更新记录统一放在 [CHANGELOG.md](CHANGELOG.md)，开发与发布要求见 [AGENTS.md](AGENTS.md)。

根目录 `tests/` 仅在本地保留，由 `.gitignore` 排除。首次克隆后如需回归，可从 v1.6.0 历史提交恢复到工作区：

```powershell
git restore --source=f6b9b1b --worktree -- tests/
```

此命令不重新跟踪测试；恢复的用例仍须按当前源码维护，修改后另行备份。缺少用例时不能据此声称回归通过。

- 核心回归：`node src/test-smart-sort.js`
- 身份与提取器：`node test-dol-mod-extractor.js`
- 打包策略：`python tests/test_pack.py`
- 本地打包：`python pack.py`

正式安装包只生成到 `release/ModHub-v<版本号>.zip`；本地保留最近三个版本，GitHub Releases 历史永久保留。打包不自动升版、提交源码或更新远端 Release。
