# ModHub

Degrees of Lewdity (DoL) 模组管理套件，基于 ModLoader 2.x 运行时与 TweeReplacer 补丁架构。

## 主要功能

1. **模组管理**：支持旁加载模组的启用、禁用、删除、拖拽排序与智能依赖拓扑排序。
2. **模组市场**：整合社区模组源与 GitHub Release，支持国内高速下载通道与断点/故障自动切换、未安装模组多选一键安装及前置依赖与冲突检查。
3. **ReadMe 浏览器**：支持离线与在线双源 Markdown 文档渲染阅读。
4. **加载日志**：提供结构化错误分析、关键词过滤及诊断长图生成导出。

## 市场多选安装（v1.0.3）

1. 打开“模组市场”，点击金框主按钮“批量下载”，勾选或点击卡片空白、标题、介绍选择未安装的模组，也可使用“全选当前筛选”。卡片内按钮和主页链接继续执行原有操作。搜索、分类和排序不会清空已选项；退出多选会清空勾选。
2. 点击“下载并安装”。若发布页含多个候选包，先选择适用的安装包，再按兼容性警告、前置依赖、所选目标的顺序核对。目标列表可独立上下滚动，每项会注明所需前置；底部显示操作数量和下载线路。仅支持外部下载或来源已失效的模组不可多选。
3. 需要安装、更新或启用的前置默认勾选，可以取消并自行处理；已安装、启用且版本满足要求的前置显示“已满足，无需下载”。快捷禁用会先列出本地及本次安装受影响的模组，成功后取消该前置的自动处理并重新检查冲突；依赖它的目标可能无法正常运行，需自行处理前置，也可主动重新勾选。批次内的框架互斥与本地冲突均会检查，有高风险冲突时须等待 5 秒后再次确认。
4. 安装按依赖顺序逐项执行。失败只阻断依赖该项的模组，独立项目继续；“停止后续安装”会等待当前操作结束，卡片“取消下载”仅取消当前下载。成功安装的项目不会回滚。
5. 完成后查看成功、失败、跳过及前置处理结果。未完成项目保留选择供重试；有实际变更时统一提示一次重载，选择“稍后重载”会留在市场页签。

已有模组继续使用原有“一键全部更新”。批量安装期间请等待任务完成后再发起其他市场安装或更新。

## 目录与工具分工

- `src/`：ModHub 模组核心源码（`boot.json`、`javascript/`、`stylesheet/`、`twee/`）。
- `release/`：由 `pack.py` 打包生成的安装包（`ModHub-v<version>.zip`），历史版本永久保留；通过 GitHub Releases 分发，不再同步至游戏 MOD 文件夹。
- `dolmod-site/`：模组市场在线索引、身份目录与反馈中心 Worker/Pages 仓库。
- `mod-identities.json`：模组市场元数据与统一身份字典。
- `dol-mod-extractor.js`：DoL 中文 Wiki 模组列表抓取、解析与身份合并脚本。
- `test-dol-mod-extractor.js`：模组身份字典与提取器的自动化校验脚本。
- `plans/`：ModHub 功能规划、版本迭代案与验收记录。

## 验证与打包

- 核心单元测试（含依赖拓扑排序与 ModLoader 契约）：`node src/test-smart-sort.js`
- 模组身份字典测试：`node test-dol-mod-extractor.js`
- 自动化打包与单目录归档：`python pack.py`，仅输出至 `release/`，同版本归档已存在时拒绝覆盖。
