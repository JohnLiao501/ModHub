## 验证边界

### 1.2.1 导入反馈核验

反馈截图选择的文件名为 `ModHub-1.2.1.zip`，提示 `bootJson文件 [boot.json] 无效`。该原生中文提示对应加载器的 `bootJsonFile boot.json Invalid`，表示 ZIP 根目录没有 `boot.json`；字段格式不通过的原生错误为另一条 `bootJson Invalid`。

正式 `ModHub-v1.2.1.zip` 含根目录清单，SHA-256 为 `750b108813da5a1554c0e58e3db2e25c5825f5eb0853f4b72be00a79fa9123ff`，与当前 GitHub Release 资产摘要一致，并通过真实加载器只读校验。两版正式清单除版本号外语义相同，本轮没有声称修复不存在的清单字段缺陷。

实际下载的 GitHub v1.2.1 自动源码归档共 57 项，清单位于 `ModHub-1.2.1/src/boot.json`，根目录缺少清单。文件名及错误均与反馈吻合，但未取得用户实际选中的 ZIP，因此其具体下载来源仍为推断。README 已补充正式附件选择与错误处理说明。

ModLoader 2.101.1 原生只读对照的最终结果：正式 1.2.1 与正式 1.2.2 均返回正确名称和版本；实际 GitHub 源码归档精确复现 `bootJsonFile boot.json Invalid`。校验未调用安装接口，独立浏览器和服务已退出。证据保存于 `资料/compat-v1.2.2/boot-feedback-native-evidence.json`。
