# 1.8.1 安全审查说明

审查日期：2026-10-21。对象为正式 ModHub 1.8.0 ZIP、对应源码，以及当日捕获的生产 Worker 和 Pages 资源。1.9.0 未作为正式版本发布，现已取消。

## 核验结果

源代码审查确认六项问题：本地说明 HTML、说明资源解压预算、管理页版本文本转义、缺少可信摘要的镜像下载、服务端授权拒绝后的换线，以及图片代理 SVG 文档权限。1.8.1 对上述客户端问题实施修复，服务端补丁须独立验证与部署。

ModHub 不附带 AI 模型或本地推理引擎。自填 AI 服务由浏览器直接请求；可指向云端或玩家自己的回环服务。发送内容、密钥保存与远程协助的数据流见 README 的“帮助中心与隐私”。没有发现自动读取并发送游戏存档的请求构造；用户自行填入的日志、源码与消息仍可能包含隐私。

远程 JS 指令和加载后的第三方模组具有完整游戏页面权限。ModHub 的确认、还原点、摘要与身份核验不能将其变成隔离沙箱，也不能撤销已经发生的网络请求。请仅使用可信来源与协助者。

## 支持范围

1.8.0 新增的 Discord 英文目录批次已撤回。旧缓存、Wiki 回退、单装、批量、历史计划及待启用路径不得重新开放此批次。已安装且启用的旧包可继续满足现有依赖；手动管理和玩家数据保留。原中文目录仅补充 Discord 来源的项目按原范围保留。

## 验证边界

代码回归、离线生产 Worker 测试、独立浏览器页面、真实来源查询与下载响应分别验收。它们均不等于完整游戏组合实测，也不保证第三方模组本身安全。未完整审查外部反向代理、Cloudflare Access 配置、D1 结构与触发器，以及所有第三方加载器和解压库代码。

本地正式产物、测试结果、生产部署及 GitHub 发布状态以本次交付回执为准；此说明本身不代表已经发布。
