## Discord Markdown 版

```markdown
**ModHub v1.4.0 已发布**

- **帮助中心**：填写自己的兼容 API 地址、模型和密钥，预览日志及源码材料后确认发送。修改方案另行预览、确认，应用前建立还原点，支持撤销；可从日志首错直接进入分析。
- **语言切换**：已声明的双语模组在同一张卡片切换语言，安装状态、版本和前置分别核对，普通与批量更新保留已安装语言。
- **加载进度**：加入 Windows 11 风格加载圆环。下载按实际比例、批量安装按完成项数显示进度，未知进度及安装等待使用加载动画。
- **市场缓存**：本机保留最近成功的目录，同次游戏切页复用，重进游戏首次检查更新，联网失败时回退缓存。【刷新市场】同时更新目录和本地资料；读取期间可切换其他标签。
- **界面排布**：日志页全屏、截图、复制日志、定位首错及获取帮助统一金框，并优化窄屏按钮排布。

更新前请先存档，安装后重新载入游戏。AI 建议不保证有效，应用后仍需重载验证；重新安装或更新目标模组会覆盖本地代码修改。

[下载 v1.4.0](https://github.com/JohnLiao501/ModHub/releases/tag/v1.4.0)
```
