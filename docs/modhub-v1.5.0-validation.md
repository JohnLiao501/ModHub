# ModHub v1.5.0 验证记录

## 本机验证

- Mod 统一入口 `node src/test-smart-sort.js` 全部通过，Node 自然退出码及外层退出码均为 0。
- 远程协助后端使用 Miniflare 的真实本地 D1 执行迁移、约束、事务与并发用例，通过 190 项关键断言；不是替代数据库的对象模拟。
- `tests/remote-assistance-browser.cjs` 使用双端浏览器、真实本地 D1 和隔离游戏的真实 ModLoader。初诊预览、确认配对、指定源码分享、补丁预览、强制还原点、事务保存、重载不重放和正式时间点还原均通过。
- 隔离游戏重载后运行修复后的故障探针；通过时间点面板还原后，原始 ZIP 摘要和原故障均复现。测试使用独立来源和存储身份，不写入玩家现有游戏数据。
- 双端页面覆盖 360px、768px 和 1280px，检查触控尺寸、横向溢出、键盘操作及底部安全距离。

## 验证边界

本机双端测试注入了开发者身份夹具，不能证明线上 Cloudflare Access 登录成功。隔离游戏未进入正常玩法，未验证 APK 实机；原游戏缺失温度计图片引发的加载事件已在本机报告中单独记录。

修复后的模组代码仍需信任开发者。时间点只覆盖模组包和管理配置，不覆盖游戏存档，也不能撤销重新载入后模组代码对存档产生的影响。

线上部署与源码发布结果以对应 Worker 部署记录、Sites 源码提交及 GitHub Release 为准，不以本机测试代替上线结果。
